## FSC → WBI

self-continuity and health behaviours.

### Model results

```{r}

#| collapse: true
```

The random-effects meta-analysis included 27 effect sizes and indicated a
**positive association between future self-continuity and health behaviours**.
The pooled effect size was
$r = 0.22 \;[0.18, 0.26], \; z = 10.50, p < 0.001$.

The magnitude of the effect size was **small**.

In addition, there was little evidence of between study heterogeneity.

### Moderator & Subgroup analysis

Because there was evidence of between study heterogeneity we will run a set of
subgroup analyses and meta-regressions of the relationship between future
self continuity and health behaviours.

#### Subgroup analyses

::: {.callout-tip}
## Is there a different effect based off sample type?
:::

First let's look at the results we get when we only consider **community**
samples.

```{r}
#| label: subgroup-1a
#| collapse: true

sub_1a <- rma(
  yi = z,
  vi = vi,
  subset = sample == "community",
  data = meta_analysis$fsc_wbi_mean$data
)

sub_1a
```

And then only for **student** samples.

```{r}
#| label: subgroup-1b
#| collapse: true

sub_1b <- rma(
  yi = z,
  vi = vi,
  subset = sample == "student",
  data = meta_analysis$fsc_wbi_mean$data
)

sub_1b
```

Let's compare both sets of results now

```{r}
#| label: subgroup-test-1
#| collapse: true

# Combine both sets of results
sample_results <- tibble(
  sample = c("community", "student"),
  estimate = c(coef(sub_1a), coef(sub_1b)),
  std_error = c(se(sub_1a), se(sub_1b)),
  tau_sq = c(sub_1a$tau2, sub_1b$tau2)
)

# Fit a fixed effects model between the studies
rma(estimate, sei = std_error, mods = ~ sample, method = "FE", data = sample_results)
```

The subgroup analysis based off sample type was non-significant,
$Q(1)   =  0.29, p  = 0.589$. The effects from community samples
$(r_{avg } =  .21 [0.16, 0.26]; k =  21)$ were not significantly different from
those obtained from the student samples
$(r_{avg}  = .23 [0.19, 0.28]; k  =  6$.
